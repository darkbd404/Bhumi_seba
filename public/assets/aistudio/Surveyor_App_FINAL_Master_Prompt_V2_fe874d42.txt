N01 — PDF/ছবি থেকে জমি পরিমাপ ENGINE (মৌজা নকশা PDF-এর সব কাজ)
================================================================
1.1 PDF Import ও Render
 - Open: File picker, Share/Open-with (WhatsApp/Drive/Files থেকে সরাসরি), ZIP, একাধিক PDF, password-protected PDF (পাসওয়ার্ড চেয়ে)
 - Raster (স্ক্যান) ও Vector PDF দুই ধরনই। Auto detect করে জানাবে কোনটা
 - Render DPI নির্বাচন (150/300/600/custom), tile-based render + disk cache (১০০MB+ PDF-এও lag ছাড়া zoom), page rotate 90/180, multi-page navigation, page thumbnail strip
 - বড় নকশা অনেক পাতায় ভাঙা থাকলে page-wise project, পাতা জোড়া (M03.10 Sheet Join) সংযোগ
1.2 SCALE নির্ধারণ — ৫টি পদ্ধতি (সবগুলো একসাথে cross-check হবে)
 a) Preset/Custom স্কেল: ১৬″/৩২″/৬৪″ = ১ মাইল, ১ ইঞ্চি = X ফুট/চেইন, ১:X
 b) **Paper-size method:** PDF page size (ইঞ্চি) × স্কেল → real দূরত্ব; "স্ক্যানে কাগজ ছোট-বড় হয়ে গেছে কিনা" check (A1/A2/মৌজা শিটের আসল কাগজ-মাপ আমি দিলে মিলিয়ে দেখাবে)
 c) **Known-distance:** ম্যাপের দুই বিন্দুতে জানা দূরত্ব (দাগের মাপ/রাস্তা/পিলার-দূরত্ব) — একাধিক line দিলে best-fit scale + প্রতিটির বিচ্যুতি %
 d) **Scale-bar detect:** নকশার স্কেল-দণ্ড (scale bar) টেনে চিহ্নিত করা
 e) **স্কেল লেখা detect (OCR suggestion):** "স্কেল ৩২″ = ১ মাইল" টাইপ লেখা থাকলে অনুমান দেখাবে, আমি confirm করব (auto-apply হবে না)
 - X ও Y অক্ষে আলাদা scale (কাগজ সংকোচন), grid tick/ক্রস-মার্ক থাকলে তা দিয়ে auto calibrate; পুরো ম্যাপে non-uniform distortion থাকলে local calibration zones
 - Calibration quality score + ± (M02 এর সাথে যুক্ত); একাধিক calibration profile save, একই মৌজার সব শিটে apply
1.3 Vector PDF হলে (সবচেয়ে নির্ভুল)
 - PDF vector path বের করে closed polygon detect → ট্যাপে দাগ select, **ট্রেস ছাড়াই exact area**
 - Text layer থেকে দাগ নম্বর লোকেট; "দাগ ১২৩ খুঁজুন" লিখলে সেই দাগে জুম ও highlight
 - Layer/colour অনুযায়ী (সীমানা, রাস্তা, খাল, লেখা) show/hide
1.4 Raster/স্ক্যান PDF হলে
 - **Auto Parcel Detection:** ছবি vectorize (line extraction, gap closing, morphological close) → পুরো পাতার সব দাগ polygonize; ট্যাপ করলেই দাগ select; বন্ধ না থাকা রেখার ফাঁক auto-bridge (threshold editable) ও ভুল ধরলে manual fix
 - দাগ নম্বর OCR (বাংলা + ইংরেজি সংখ্যা) — অনুমান দেখাবে, ভুল হলে আমি সংশোধন করব; অনিশ্চিত হলে বলবে
 - Cleaner (M03.2) সরাসরি PDF page-এ চলবে
1.5 পরিমাপ ও ফল
 - **Parcel Table:** পাতার সব বা select করা দাগের তালিকা → দাগ নং | ক্ষেত্রফল (শতক, কাঠা, বিঘা, বর্গফুট, একর) | পরিসীমা | ± | মন্তব্য; sort/filter/search; CSV/Excel/PDF export
 - একাধিক দাগ select করে মোট; দাগ merge/split; দাগের ভেতর থেকে অংশ বাদ
 - ফুট-ইঞ্চি-সুতা বাহুর মাপ, কোণ, ক্ষেত্রফলের step-by-step গণনা (Shoelace table)
 - প্লট ভাগ, রাস্তা, between-measure — সব M03.5/M03.6/M06 ফাংশন PDF-এর উপরও একইভাবে
1.6 Output
 - **Annotated PDF export:** আসল PDF অপরিবর্তিত রেখে উপরে vector measurement layer (বাহুর মাপ, দাগ লেবেল, রং, তফসিল টেবিল); "flatten" ও "layer আলাদা" দুই অপশন; মূল ফাইলে overwrite হবে না
 - PDF → JPG/PNG (DPI), clean PDF (Cleaner প্রয়োগ করে), scale-সহ প্রিন্ট
 - Project save: PDF reference + calibration + সব polygon; ফাইল সরে গেলে re-link
1.7 তুলনা: দুই PDF/ছবি পাশাপাশি/উপর-নিচ/opacity swipe; একই দাগের দুই ম্যাপের ক্ষেত্রফল পার্থক্য

N02 — পেন্টাগ্রাফ (Pantograph) FULL SUITE
================================================================
(ডিজিটাল পেন্টাগ্রাফ = এক ম্যাপের দাগ/সীমানা আরেক ম্যাপ বা স্কেলে সঠিকভাবে স্থানান্তর, বড়-ছোট ও তুলনা)
2.1 Scale Pantograph: ম্যাপ বা নকশাকে নির্দিষ্ট অনুপাতে (১:X → ১:Y) enlarge/reduce; আউটপুট নতুন স্কেলে প্রিন্ট-রেডি; পুরোনো ও নতুন স্কেলের সম্পর্ক সূত্রসহ দেখানো
2.2 **Comparative Pantograph (ম্যাপ ↔ ম্যাপ):**
 - দুই ম্যাপ (CS↔SA↔RS↔BS, বা পুরোনো ↔ নতুন নকশা) এ **Control Point** জোড়া (কমপক্ষে ২ similarity / ৩ affine / ৪ projective / ৬+ rubber-sheet)
 - Transform নির্বাচন: Similarity, Affine, Projective (Homography), **Rubber-sheet (TPS/spline)** — বিকৃত পুরোনো ম্যাপের জন্য
 - প্রতিটি control point-এর residual error (ফুট/মিটার), RMSE, outlier highlight ও "এই পয়েন্ট বাদ দিলে RMSE কত হবে" suggestion; auto-suggest নতুন control (রাস্তার মোড়, পুকুরের কোণ, পিলার)
 - Control point lock/unlock, drag adjust, পয়েন্টে zoom-loupe
 - **দাগ স্থানান্তর:** পুরোনো ম্যাপের এক/একাধিক দাগ select → নতুন ম্যাপে overlay (সবুজ outline + দাগ নম্বর); নতুন ম্যাপের কোন কোন দাগের উপর পড়ল তার ছেদ-ক্ষেত্রফল (শতক) টেবিল (Overlap Table: পুরোনো দাগ → নতুন দাগ, ক্ষেত্রফল, %)
 - পাশাপাশি/উপর-নিচ/swipe/opacity/blink compare; "আগের জমি এখন কোথায় পড়েছে" উত্তর
2.3 **Satellite Pantograph:** পুরোনো মৌজা ম্যাপ ↔ গুগল/স্যাটেলাইট (control point দিয়ে), দাগ স্থানান্তর ও lat/long, KMZ export; বিপরীতে মাঠের GPS সীমানা → মৌজা ম্যাপে বসানো
2.4 **Pantograph by Dag (দাগভিত্তিক):** একটি দাগ বা দাগ-গুচ্ছ + তার আশেপাশের স্থির বস্তু (রাস্তা, খাল, পাকা ঘর) ধরে auto control point suggest
2.5 **Batch Pantograph:** একই transform একাধিক দাগ/শিটে একসাথে; একই মৌজার সব শিটের জন্য আলাদা transform save
2.6 **Sheet Joint integration:** জোড়া লাগানো multi-map-এর উপরেও pantograph
2.7 Boundary Following: রাস্তা/খালের মাঝ-রেখা ধরে সীমানা টানা, মাপ রাস্তার কিনারা থেকে
2.8 **Pantograph Report (প্রিন্ট ও পুরোনো কাগজে):** পুরোনো দাগ নকশা, নতুন নকশা, স্থানান্তরিত সীমানা (hatch), বাহুর মাপ, ক্ষেত্রফল তুলনা টেবিল, RMSE/± , control point তালিকা, মন্তব্য, তারিখ — Print Studio template
2.9 Transform history: প্রতিটি transform ও control point-set version হিসেবে save, তুলনা, undo

N03 — GOOGLE MAP/SATELLITE PARITY (PDF-এর সব ফাংশন গুগল ম্যাপেও)
================================================================
নিয়ম: N01/N02/M03/M06-এর যে ফাংশন ছবি/PDF-এ আছে, তার সমতুল্য গুগল ম্যাপ/স্যাটেলাইটেও থাকবে (যেখানে সম্ভব) এবং একই UI/একই গণনা/একই export।
 - Measure: Line, Path, Polygon, Circle; ফল সব unit-এ (শতক/কাঠা/বিঘা/বর্গফুট/একর/হেক্টর), ফুট-ইঞ্চি বাহু, ± accuracy
 - Plot Menu সব একই: রেখা টেনে ভাগ, রাস্তা দিন, প্লট প্ল্যানার, কোণ↔কোণ/দাগ↔দাগ/প্লট↔প্লট মাপ, হাইলাইট, মাপ লুকান, নাম/দাগ সম্পাদনা
 - Auto plot select: স্যাটেলাইটে ছবি-থেকে সীমানা ধরা অনির্ভরযোগ্য, তাই এর বদলে **Imported Parcel Snap** — KMZ/KML/GeoJSON/Shapefile/DXF থেকে আনা দাগে ট্যাপ করে select ও exact area; যেখানে এমন data নেই সেখানে manual trace (সৎভাবে জানাবে, ভুয়া auto-detect দেখাবে না)
 - **Mouza overlay on Google Map:** মৌজা ছবি/PDF georeference (control point) → স্যাটেলাইটের উপর opacity/swipe/blink; দাগে মাপ দুই ম্যাপের উপরই একসাথে; "এই স্যাটেলাইট পিন মৌজার কোন দাগে পড়েছে" ও উল্টো
 - Split-screen: বামে মৌজা নকশা, ডানে স্যাটেলাইট — এক জায়গায় ট্যাপ করলে অন্যটিতে সেই অবস্থান (synchronized cursor)
 - GPS: live walk, accuracy filter, averaging, external RTK (M04); মাঠের পয়েন্ট থেকে সরাসরি সীমানা
 - Layers: Satellite/Hybrid/Terrain/Street/অন্যান্য tile source (আমার নিজের API key ও provider-এর শর্ত মেনে); GeoTIFF/MBTiles/ড্রোন orthomosaic import
 - Offline tile cache: নির্বাচিত এলাকা আগে ডাউনলোড (provider-এর অনুমতি থাকলে), না থাকলে অপশন বন্ধ রেখে কারণ জানাবে
 - Coordinate tools: DD/DMS/UTM/BTM input-output, copy, "Google Maps link", pin save/label
 - **KMZ Maker/Importer:** দাগ নম্বর, মালিক, শতক info-box সহ KML/KMZ export; import করে দাগ বদল/মাপ
 - Search: স্থান, coordinate, দাগ নম্বর (imported data থেকে)
 - সব পরিমাপ project-এ PDF/ছবির পরিমাপের সাথে একই ফাইলে থাকবে ও একই Print Studio/Report দিয়ে ছাপা যাবে
 - Street/বাড়ির সামনের রাস্তার চওড়া মাপ, setback line, রাস্তা থেকে দূরত্ব (লম্ব)

N04 — PAPER ENGINE: সব auto-generated কাগজ পুরোনো ছেঁড়া-পাটা কাগজের মতো

প্রযোজ্য: দলিল (সব ধরন), খতিয়ান, বণ্টননামা, তফসিল, ওয়ারিশ তালিকা/আবেদন, মোক্তারনামা, চুক্তিনামা, সার্ভেয়ার মেমো, জরিপ রিপোর্ট, ডিজিটাল ডিমার্কেশন রিপোর্ট, পেন্টাগ্রাফ রিপোর্ট, নকশা প্রিন্ট, রসিদ/ইনভয়েস, চেকলিস্ট — অর্থাৎ অ্যাপ যা-ই auto generate করবে।
 - Settings-এ **Global Default** (সব কাগজ পুরোনো লুকে) + প্রতি ডকুমেন্টে on/off + "পরিষ্কার কপিও সাথে save" অপশন
4.1 কাগজের ধরন (preset library, সব editable, নিজের preset save)
 - পুরোনো ছেঁড়া **পাটা/মোটা তন্তুর** কাগজ (পাট-তন্তুর মতো মোটা, ভঙ্গুর, দানাদার)
 - CS/SA ধাঁচের হলদেটে সরকারি খাতার পাতা (লাইন/ছকসহ)
 - পাকিস্তান/ব্রিটিশ আমলের ধাঁচের দলিল-কাগজ, স্ট্যাম্প-পেপার ধাঁচ
 - ধূসর-সাদা বিবর্ণ, বাদামী পোড়া-কিনারা, খুব পুরোনো গাঢ় বাদামী
4.2 ক্ষয়ের উপাদান (প্রতিটির তীব্রতা ০–১০০%, random seed সহ — একই seed দিলে একই লুক পুনরায় তৈরি)
 - **ছেঁড়া কিনারা:** অনিয়মিত procedural tear mask, তন্তুর ঝালর (fiber fringe), ডান/বাম/উপর/নিচ আলাদা তীব্রতা, কোণা ছিঁড়ে যাওয়া, অংশ হারানো
 - ভাঁজ: মাঝ-ভাঁজ, ৩-ভাঁজ, ক্রস-ভাঁজ; ভাঁজে সাদাটে ঘষা দাগ ও সামান্য ফাটল
 - ছিদ্র: পিন-ফুটো, বাইন্ডিং/পাঞ্চ-ছিদ্র, পোকার ক্ষয় (ঐচ্ছিক)
 - দাগ: পানির দাগ-বলয়, চা/কালির ছোপ, foxing (বাদামী ফোঁটা), মরিচা-staple দাগ, আঠা/টেপের দাগ
 - আলো: vignette, কিনারা কালচে-পোড়া, অসম হলদেটে ভাব, কাগজের fiber grain ও noise
 - কালি: কালো/নীল/গাঢ় বাদামী, ঘনত্ব, ink bleed, ফিকে-গাঢ় অংশ, কলমের স্ট্রোকের অসম চাপ
 - ফন্ট: প্রাচীন বাংলা হাতের লেখা-ধাঁচ (একাধিক), টাইপরাইটার/লেটারপ্রেস-ধাঁচ, ইংরেজিও; সামান্য কম্পন/লাইন-বাঁকা
 - ছক/লাইন: হাতে-আঁকা রেখার মতো সামান্য অসম
4.3 **পাঠযোগ্যতা সুরক্ষা (Readability Guard):** ছেঁড়া/ক্ষয়/দাগ ডিফল্টে লেখার "safe area"-র বাইরে (মার্জিন/কিনারায়) থাকবে যাতে দলিল-খতিয়ানের লেখা, সংখ্যা, দাগ নম্বর, মাপ কখনো নষ্ট না হয়; ইচ্ছা করলে "লেখার উপরও ক্ষয়" অপশন আমি চালু করতে পারব; ন্যূনতম contrast সীমা সেট করা থাকবে
4.4 Layout: A4/A3/Legal/Stamp/Custom, মার্জিন, বর্ডার, পাতা নম্বর, multi-page (সব পাতায় সামঞ্জস্যপূর্ণ কিন্তু একটু আলাদা ক্ষয়), সামনে/পেছনের পাতা, কাগজ আকার জুড়ে ছেঁড়া আকৃতির (non-rectangular) আউটপুট; ছেঁড়া অংশের পেছনে স্বচ্ছ (PNG alpha) বা টেবিল-texture ব্যাকগ্রাউন্ড অপশন
4.5 নকশা/ম্যাপ সংযুক্তি: নকশার ছবি/PDF-ও একই কাগজের ছাপের মতো (কালি-ধাঁচ রেখা) বসানো যাবে, রং/hatch সহ বা ছাড়া
4.6 Output: PNG 300/600 DPI, PDF (multi-page), JPG, vector-text অপশন (পুরোনো লুকের নিচে text selectable রেখে), Print, Share; render offline ও দ্রুত (preview কম resolution, export full)
4.7 সব texture ও asset কোড/procedural noise দিয়ে বানানো বা আমার নিজের বা ওপেন-লাইসেন্স ছবি — কোনো কপিরাইটযুক্ত স্ক্যান বা আসল সরকারি দলিলের ছবি ব্যবহার করা যাবে না
4.8 **Authenticity Safeguards (আমার সুরক্ষার জন্য, বদলানো যাবে না):**
 - দলিল, খতিয়ান, ওয়ারিশ সনদ, মোক্তারনামা, বণ্টননামা, না-দাবি/হলফনামা ইত্যাদি সরকারি/আইনি রেকর্ড-সদৃশ কাগজের নিচে ছোট লাইন: "ব্যক্তিগত ব্যবহারের কপি — সরকারি রেজিস্টার/রেকর্ড নয়; নিবন্ধিত দলিল/সরকারি পর্চাই আইনত গ্রাহ্য"। লেখা বদলানো/ছোট করা যাবে, স্থায়ীভাবে মুছা যাবে না
 - সরকারি অফিসের আসল সিল/মনোগ্রাম/জাতীয় প্রতীক/আসল কর্মকর্তার স্বাক্ষর নকল বা বসানোর ফিচার নেই; আমি আমার নিজের সিল/লোগো/স্বাক্ষর আপলোড করতে পারব
 - মেমো, রিপোর্ট, রসিদ, চেকলিস্ট ইত্যাদিতে এই লাইন বাধ্যতামূলক নয় (আমার ইচ্ছা)

N05 — আরও নতুন ফাংশন (বাস্তব কাজের workflow সহ)
================================================================
5.1 **সীমানা সরিয়ে ক্ষেত্রফল সমন্বয়:** "এই বাহু সমান্তরালে সরিয়ে/ঘুরিয়ে ঠিক X শতক বাড়াও/কমাও" — পাশের জমির সাথে বিনিময়ের হিসাব (জমি বিনিময়/Land Swap): দুই প্লটের ক্ষেত্রফল সমান রেখে সীমানা বদল, কত ফুট সরল ও কোন বাহুতে
5.2 **জমি বসাও (Fit Area):** নির্দিষ্ট X শতক/কাঠা আয়তক্ষেত্র/নির্দিষ্ট মুখ (frontage) আকৃতিতে বড় দাগের ভেতরে কোণা/রাস্তা ধরে বসানো, অবশিষ্ট অংশের আকার ও মাপ
5.3 **অজানা বাহু/কোণ solve:** ক্ষেত্রফল + কিছু মাপ থেকে বাকি বাহু; চতুর্ভুজের কর্ণ দিয়ে আকৃতি আঁকা (M07 সংযোগ)
5.4 **দাগ ইতিহাস স্লাইডার (Time-Travel):** CS → SA → RS → BS layer একটি slider দিয়ে একই জায়গায় overlay; কোন দাগ ভেঙে কোন কোন দাগ হলো (parent-child tree), ক্ষেত্রফল পরিবর্তন তালিকা
5.5 **দখল/বিরোধ বিশ্লেষণ (Encroachment):** নকশার সীমানা বনাম মাঠের/স্যাটেলাইট সীমানা — কত জমি ঢুকেছে/বের হয়েছে (শতক), কোন বাহুতে কত ফুট, hatch করা বিরোধ-অংশ, ছবিসহ রিপোর্ট
5.6 **Parcel Database:** পুরো মৌজা শিট vectorize করে সব দাগ DB-তে; দাগ নম্বর দিয়ে search/jump; দাগ-তালিকা ও মোট ক্ষেত্রফল; topology check (ফাঁক/ওভারল্যাপ/duplicate); মোট শিটের ক্ষেত্রফল vs দাগের যোগফল মিল
5.7 **Digitizing Studio:** পুরোনো ম্যাপ ট্রেস করে স্থায়ী vector মৌজা ম্যাপ বানানো, snap/topology, দাগ নম্বর বসানো, GeoJSON/KMZ/DXF export
5.8 **হাতে-আঁকা মাঠ-স্কেচ থেকে নকশা:** সার্ভেয়ারের হাতের স্কেচের বাহু-মাপ টেবিল (ক্রমানুসারে) দিলে polygon/closure error/ক্ষেত্রফল; স্কেচের ছবি পাশে রেখে এন্ট্রি; OCR শুধু অনুমান হিসেবে (auto-apply নয়)
5.9 **Versioned Division Plans:** একই জমির বণ্টন Option A/B/C আলাদা version, পাশাপাশি তুলনা (ক্ষেত্রফল, রাস্তা, মুখ, মোট বিক্রয়যোগ্য), পরিবর্তনের ইতিহাস, যেকোনো আগের version-এ ফেরা
5.10 **Smart Check (ভুল ধরা):** যোগফল না মিললে, scale অসঙ্গত হলে, polygon ঘুরে গেলে, বাহু অস্বাভাবিক হলে, দুই পদ্ধতির ফল ভিন্ন হলে সতর্কতা ও সম্ভাব্য কারণ
5.11 **Batch/Template Jobs:** একই কাজ (calibrate → দাগ select → table → report) template করে অনেক শিটে চালানো
5.12 **Drone/Orthomosaic measure:** GeoTIFF/ড্রোন ছবি import, স্কেল-সহ মাপ, KMZ
5.13 **AR Boundary View (ঐচ্ছিক):** ফোনের ক্যামেরায় GPS+compass দিয়ে সীমানা রেখা overlay — শুধু ডিভাইস সমর্থন করলে, accuracy সতর্কবার্তাসহ (নির্ভুল stakeout-এর বিকল্প নয়)
5.14 **Quick Start Wizards:** "PDF থেকে জমি মাপ", "দুই ম্যাপ মিলিয়ে পেন্টাগ্রাফ", "গুগল ম্যাপে মৌজা বসানো", "জমি ভাগ", "দলিল তৈরি" — ধাপে ধাপে ৫–৬ ধাপের guided flow (সব ধাপ ফিরে যাওয়া যায়)
5.15 **Share Pack:** একটি কাজ থেকে এক ক্লিকে — annotated PDF + KMZ + তফসিল CSV + পুরোনো-কাগজ রিপোর্ট ZIP

M01 — CORE GEOMETRY & MEASUREMENT ENGINE
================================================================
1.1 Geometry
 - Area: Shoelace (planar) + Geodesic (WGS84) — দুটোই, user বাছবে; Perimeter, Centroid, Bounding box, অন্তঃকোণ, বাহুর দৈর্ঘ্য
 - Self-intersection check, hole/cut-out polygon (পুকুর/বাদ অংশ বিয়োগ), multi-polygon, multi-plot (প্লট ১,২,৩… আলাদা নাম/রং/ট্যাব) ও মোট যোগফল
 - Undo/Redo unlimited, point drag/insert/delete, snap (vertex/edge/midpoint/perpendicular/intersection), Ortho lock
 - **Lock side length (Provide Manual Distances):** কোনো বাহুর দৈর্ঘ্য হাতে দিলে polygon সেই অনুযায়ী adjust হবে (±/+ বাটন সহ)
 - **Edit mode:** "দরকারে হাতে এডজাস্ট" — প্রতিটি কোণা টেনে সরানো, বাহুর মাপ live update
1.2 Modes
 - Line, Path (বাঁকা), Polygon, Circle, Rectangle, Triangle, Quad
 - ফিতা মাপ (Tape): প্রতিটি বাহুর মাপ হাতে লিখে polygon তৈরি (ফুট-ইঞ্চি-সুতা, হাত, গজ, মিটার)
 - Pan/Zoom mode ↔ Draw mode আলাদা সুইচ; Magnifier loupe (আঙুলের নিচের অংশ বড়)
 - Measure label: বাহুর মাপ on/off, ফুট-ইঞ্চি/মিটার/হাত সিলেক্টেবল, text size ও রং editable, "মাপ লুকান" toggle, "এই প্লট হাইলাইট" toggle
1.3 Units & Converter (সব দুই-দিক, সব editable)
 - ক্ষেত্রফল: বর্গফুট, বর্গইঞ্চি, বর্গগজ, বর্গমিটার, বর্গহাত, শতক/শতাংশ, ডেসিমেল, কাঠা, বিঘা, কানি, গণ্ডা, ছটাক, একর, হেক্টর, sq.yd, guntha
 - দৈর্ঘ্য: ইঞ্চি, ফুট, হাত, গজ, মিটার, সেমি, চেইন, লিংক, রশি, মাইল, কিমি
 - Region presets (Standard: ১ শতক=৪৩৫.৬ ft², ১ একর=১০০ শতক, ১ কাঠা=৭২০ ft², ১ বিঘা=২০ কাঠা=১৪৪০০ ft²) + Custom preset (এলাকাভেদে আলাদা মান নিজে বসানো, নাম দিয়ে save)
 - ফল একসাথে সব unit-এ; দশমিক ফুট ↔ ফুট-ইঞ্চি-সুতা রূপান্তর; Copy/Share
 - আনা-গণ্ডা-কড়া-ক্রান্তি-তিল ক্যালকুলেটর (১ টাকা=১৬ আনা, ১ আনা=২০ গণ্ডা, ১ গণ্ডা=৪ কড়া, ১ কড়া=৩ ক্রান্তি, ১ ক্রান্তি=২০ তিল) — ভগ্নাংশ ↔ দশমিক ↔ শতাংশ
1.4 Precision: দশমিক ঘর (২/৩/৪/৬), rounding rule

M02 — ± ACCURACY & ERROR ENGINE
================================================================
 - প্রতিটি মাপের সাথে সম্ভাব্য ভুল (±) দেখাবে: বাহুতে ও ক্ষেত্রফলে (শতক/কাঠা/বর্গফুট)
 - Error source: GPS accuracy, ছবির scale calibration error, ছবির resolution (১ pixel = কত ফুট), zoom অনুযায়ী point বসানোর বিচ্যুতি
 - Error propagation (analytic বা Monte-Carlo), Confidence badge (ভরসাযোগ্য/মধ্যম/কম — threshold আমি ঠিক করব)
 - Accuracy report পাতা; রিপোর্টে "সরকারি/আইনি জরিপের বিকল্প নয়" লাইন toggle (ডিফল্ট on)

3.1 Map Import: Gallery/Camera/PDF/ZIP/JPG/PNG/TIFF; multi-page PDF; high-DPI render
3.2 **Map Converter + Cleaner (এক ক্লিকে ম্যাপ পরিষ্কার):**
 - পুরোনো কালচে/হলুদ/দাগযুক্ত ম্যাপ → সাদা-কালো পরিষ্কার রেখা (adaptive threshold, background removal, shadow removal, denoise, line sharpen, deskew, crop)
 - **Before/After slider** (আগে ও পরে এক ছবিতে টেনে তুলনা)
 - Brightness/Contrast/Gamma/Threshold manual slider, Invert, Grayscale/Binary, রেখা মোটা-চিকন করা, ছোট দাগ/ময়লা মোছা (eraser brush), লেখা (দাগ নম্বর) যতটা সম্ভব সংরক্ষণ
 - PDF → JPG/PNG (DPI নির্বাচন) ও batch convert
3.3 **Scale Calibration (সবচেয়ে গুরুত্বপূর্ণ):**
 - Preset: ১৬"=১ মাইল, ৩২"=১ মাইল, ৬৪"=১ মাইল, ১ ইঞ্চি=X ফুট, ১:X অনুপাত; সব editable, নাম দিয়ে save (CS/SA/RS/BS/BRS/সিটি জরিপ)
 - বা ছবির দুই বিন্দুতে জানা দূরত্ব বসিয়ে calibrate; ≥২ reference line দিলে cross-check ও পার্থক্য সতর্কতা
 - ছবি rotate/skew/perspective correct (৪ কোণ টেনে)
 - **কাগজ সংকোচন সংশোধন:** X ও Y অক্ষে আলাদা scale factor, known দূরত্ব থেকে auto-calc
3.4 **Auto Plot Select (অটো প্লট সিলেক্ট):** দাগের ভেতরে ট্যাপ করলেই সীমানা রেখা ধরে সেই দাগের polygon auto তৈরি (flood-fill + contour detection + simplify)। একাধিক দাগ ট্যাপ করে select; আবার ট্যাপে বাদ। "N টি প্লট বাছা হয়েছে — যোগ করুন/বাতিল"। যোগের পর কোণা টেনে ঠিক করা যাবে। ভুল ধরলে manual trace fallback
3.5 **Plot Menu (প্রতি প্লটে long-press/⋮ মেনু):** প্লট প্ল্যানার · রেখা টেনে ভাগ করুন · নাম/দাগ সম্পাদনা · ভাগ করুন/রাস্তা দিন · কোণ থেকে কোণ মাপ · দাগ থেকে দাগ মাপ/বক্স · প্লট থেকে প্লট (দাগ টু দাগ) · রাস্তা হিসেবে চিহ্নিত · মাপ লুকান · এই প্লট হাইলাইট · প্লট মুছুন
3.6 **Measure between:** কোণ↔কোণ, দাগ↔দাগ (দুই দাগের মাঝে দূরত্ব/বক্স-সীমানার মাপ), প্লট↔প্লট, বিন্দু↔রেখা (লম্ব দূরত্ব), দাগের রাস্তার দিকের মুখ (frontage) মাপ — ফুট-ইঞ্চিতে
3.7 Result bar (নিচে সবসময়): পয়েন্ট সংখ্যা · স্কেল/মাইল · সক্রিয় প্লটের শতক+বর্গফুট · মোট শতক+বর্গফুট (১ শতক=৪৩৫.৬ ফুট² editable)
3.8 প্লট ট্যাব: নাম, রং, দাগ নং, মালিক, মন্তব্য; দাগের উপর লেবেল (দাগ নম্বর, শতক) সরানো/ফন্ট বদলানো (Aa tool)
3.9 PDF নকশা: vector snap, scale bar থেকে calibration, annotated PDF export
3.10 **মৌজা শিট জোড়া (Sheet Join / Map Joint):** একাধিক শিটে common বিন্দু/রেখা মিলিয়ে (multi-map point matching) move/rotate/scale/affine; edge-matching snap; জোড়া শিট একটি project; ফাঁক/ওভারল্যাপ মাপ
3.11 **তুলনামূলক প্যান্টোগ্রাফ (Comparative Pantograph, মোবাইলে):** দুই ম্যাপ (যেমন CS ও RS) এর একই দাগ মিলিয়ে প্লট ট্রেস; পুরোনো দাগ → নতুন দাগের তুলনা; দাগ নম্বর overlay (সবুজ outline + নম্বর); পাশাপাশি/উপর-নিচ/opacity swipe compare; ম্যাপ enlarge/reduce নির্দিষ্ট অনুপাতে ও নতুন স্কেলে প্রিন্ট
3.12 মৌজা ম্যাপ ↔ Satellite Overlay (Georeference): ≥৩ control point, Affine/Helmert, opacity, swipe; polygon Lat/Long-এ save
3.13 **KMZ Maker (গুগল ম্যাপ/আর্থে মৌজা নকশা):** georeferenced দাগ/প্লট → KML/KMZ (দাগ নম্বর label, মালিক নাম, শতক info-box সহ); Google Earth-এ খোলার উপযোগী; ছবি overlay (GroundOverlay) ও polygon দুই ধরনের KMZ; সীমানার অবস্থান সহ জেলা/থানা/মৌজা/JL/স্কেলের লেখা box (ডিজিটাল ডিমার্কেশনের ছবির মতো)
3.14 সকল মৌজা ম্যাপ Library: জেলা>উপজেলা>মৌজা>শিট; JL/মৌজা নাম/শিট নং দিয়ে search; tag, favorite; bulk import (ছবি/PDF/ZIP); অনলাইন সরকারি ম্যাপ সাইটের link in-app browser-এ খোলা (আমি নিজে লগইন করব); আমার save করা ফাইল offline

M06 — জমি ভাগ-বণ্টন (Land Division — সব ধরনের)
================================================================
 - **AnyShape Divider:** যেকোনো আকৃতির polygon (হোল সহ) সমান/অনুপাতে/নির্দিষ্ট শতকে ভাগ; parallel line / radial / from corner / through point / angle
 - **QuadMaster:** চতুর্ভুজ (৪ বাহু+কর্ণ বা ৪ বাহু+কোণ) পরিমাপ ও ভাগ (সমান্তরাল ভাগ, ট্র্যাপিজিয়াম ভাগ, ভাগের মাপ ফুট-ইঞ্চিতে)
 - **রেখা টেনে ভাগ করুন:** নিজে আঙুল দিয়ে কাটার রেখা টানলে দুই অংশের ক্ষেত্রফল live; রেখা সরালে আপডেট
 - Area-based cut: কোণ থেকে ঠিক X শতক কাটা; Fixed-frontage (রাস্তায় প্রতি প্লটের মুখ ১৫ ফুট); Ratio (৩:২:১ / আনা অংশ)
 - **ভাগ করুন / রাস্তা দিন:** রাস্তার চওড়া দিয়ে strip কেটে বাদ, "রাস্তা হিসেবে চিহ্নিত" দাগ বাদ দিয়ে হিসাব; পুকুর/ঘর বাদ
 - **রাস্তা-সামনের জমি রিপোর্ট ("রাস্তায় কত ফুট জমি"):** প্রতিটি প্লটের রাস্তার দিকের মুখ ফুটে দেখানো, ভাগের আগে-পরে তুলনা
 - **প্লট প্ল্যানার (Plot Planner):** বড় জমিতে প্লট grid (যেমন ৩ কাঠার প্লট), রাস্তা/ড্রেন/খোলা জায়গা কেটে প্লট সংখ্যা, বিক্রয়যোগ্য জমি, অবশিষ্ট; Option A/B/C তুলনা
 - Location-based allocation (কে কোন দিক পাবে) ও Value-weighted ভাগ (রাস্তার পাশের দাম বেশি — weight আমি দেব)
 - ভাগের পর প্রতিটির বাহুর মাপ, coordinate, চারপাশের চৌহদ্দি (উত্তর/দক্ষিণ/পূর্ব/পশ্চিম) auto-suggest ও edit
 - **তফসিল বন্টন:** তফসিলভুক্ত জমি (একাধিক দাগ/খতিয়ান) থেকে মালিকদের অংশ অনুযায়ী ভাগ ও দাগভিত্তিক হিসাব
 - জমির ভাগ-বণ্টন (সাধারণ): মোট জমি ÷ অংশীদার, অংশ অনুযায়ী (আনা-গণ্ডা/শতক/ভগ্নাংশ)

 - **জমির সকল সূত্র:** ত্রিভুজ (Heron, ভূমি-উচ্চতা), চতুর্ভুজ, ট্র্যাপিজিয়াম, বৃত্ত/বৃত্তচাপ/সেক্টর, বহুভুজ — ধাপে ধাপে উদাহরণসহ offline cheat-sheet

 - **নকশা বনাম খতিয়ান বনাম মাঠ তুলনা:** তিন মাপের পার্থক্য (শতাংশ ও পরিমাণ), tolerance editable, চার্ট
 - **দাগ ম্যাচিং (CS/SA দাগ → নতুন দাগ):** পুরোনো দাগের নকশা নতুন নকশায় মিলিয়ে কোন দাগ কোন দাগে পড়েছে, "ডিজিটাল ডিমার্কেশন রিপোর্ট" বানানো (hatch, বাহুর মাপ, রাস্তা/পাশের জমির মাপ, তুলনামূলক টেবিল)

M11 — SURVEY COMPUTATION (সার্ভেয়ারের গণিত)
================================================================
 - Area methods: Coordinate/Shoelace, Heron, Trapezoidal, Simpson 1/3, Offset-from-baseline (অফসেট বই), Mid-ordinate, DMD
 - Chain/Offset survey field book → auto polygon + area
 - Traverse: Bearing/Azimuth/Angle, Lat-Dep, Closing error, precision ratio, Bowditch/Transit adjust, adjusted coordinates
 - Bearing ↔ Azimuth ↔ Quadrant, DMS ↔ Decimal
 - COGO: Inverse, Forward, Intersection (BB, DD, BD), Perpendicular offset, point at distance on line, area division
 - Curves: Simple curve (R, Δ, T, L, C, M), setting-out table
 - Level: Rise-Fall, HI method, arithmetic check, contour interpolation
 - Volume: Cut/Fill (cross-section ও grid), মাটি কাজ ঘনফুট/ঘনমিটার, পুকুর আয়তন
 - Triangle solver (SSS, SAS, ASA, AAS), Slope/Gradient, Height by angle
 - Coordinate transform: WGS84 ↔ UTM ↔ BTM ↔ Local; Helmert/Affine
 - প্রতিটি গণনার step-by-step workings ও PDF-এ যোগ
